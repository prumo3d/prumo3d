# Política de Segurança

O Prumo 3D é software livre e de código aberto, baseado no FreeCAD. Incentivamos o relato responsável de
vulnerabilidades de segurança que possam afetar quem usa o programa e vamos nos empenhar para corrigi-las
quando forem descobertas.

## Recompensas

O Prumo 3D não tem programa de recompensa em dinheiro por falhas de segurança. Vulnerabilidades usadas
como moeda de troca para exigir recompensas não serão atendidas.

## Versões com suporte

As correções de segurança são aplicadas na versão estável atual e no ramo de desenvolvimento.

| Ramo | Base | Suporte |
|---|---|---|
| `prumo-1.1` | FreeCAD 1.1.4 | :white_check_mark: |
| `prumo-main` | Desenvolvimento | :white_check_mark: |

## Como relatar uma vulnerabilidade

Use a ferramenta de relato de segurança do GitHub, que mantém o relato privado até a correção:
https://github.com/prumo-engenharia/Prumo3D/security/advisories/new

Se a vulnerabilidade estiver no código do FreeCAD original (e não nas partes da Prumo), relate também ao
projeto FreeCAD pelo canal deles:
https://github.com/FreeCAD/FreeCAD/security/advisories/new
